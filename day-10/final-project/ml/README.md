# FacilityOps Machine Learning Track Notice

## 1. Selected Training Track
This project was implemented under the **Web Development Track (Full-Stack Enterprise Applications)**. 

The **AI / Machine Learning Track** was **not selected** for this final capstone submission.

---

## 2. Integrity & Architecture Policy
In accordance with engineering standards and internship evaluation guidelines, **no synthetic or fake ML models** have been included in this repository. All statistical summaries, compliance grading, and predictive telemetry displayed on the frontend dashboard are computed deterministically using standard mathematical aggregation and domain business logic.

---

## 3. Reserved for Future ML Extensions
This directory is preserved as a placeholder for post-capstone roadmap enhancements:
1. **Predictive Maintenance Forecasting**:
   - Model: Random Forest Regressor / XGBoost or Prophet time-series models.
   - Purpose: Predicting HVAC compressor or chiller unit failure before critical alerts trip, based on vibration and temperature time-series telemetry.
2. **Automated Inspection Defect Classification**:
   - Model: Multi-class NLP classifier (DistilRoBERTa or fine-tuned BERT).
   - Purpose: Parsing raw inspector text notes into standardized building code violation tags and severity ratings.
3. **Computer Vision Building Envelope Inspection**:
   - Model: YOLOv8 / Faster R-CNN.
   - Purpose: Automated detection of concrete spalling, facade cracking, and roofing moisture accumulation from drone photography.
